# hymytalli

Single-file static demo website for **hymytalli**, an independent garage and custom
vehicle care workshop on Avaruuskatu 6 in the Haukilahti / Westerås area of Espoo.

## Open it

Double-click `index.html` in any browser, or serve the folder statically:

```
npx serve .
```

No build step, no dependencies. All CSS and JS are inline; the only external
requests are one Google Font and photos from images.unsplash.com.

Demo website.
